Guidelines for Prompt Names
Creating Effective Prompt Names

Please find these guidelines when naming your prompts:

  • Be Descriptive: Capture the main idea of the prompt in a concise manner.
  • Be Specific: Avoid generic names; instead, focus on the unique aspects of your prompt.
  • Keep it Concise: Aim for 2-5 words that effectively summarize the prompt.
What to Avoid:
  • Random or arbitrary numbers
  • Author names or dataset names
  • Overly generic descriptions (e.g., "Good Prompt", "Translation Task")
  • Extremely long names
Example:

For a machine translation prompt:

please translate the following sentence as if you are an English instructor teaching your students:

{{source_sentence}}
|||
{{target_sentence}}

A suitable name would be: "English Instructor Style Translation"
