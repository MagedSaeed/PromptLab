Guidelines for Prompt Tags
Creating Effective Prompt Tags

Please find these guidelines when adding tags to your prompts:

  • Be Specific: Use tags that describe distinct properties of the prompt.
  • Use Established Terms: Prefer widely recognized terms in the field of prompt engineering.
  • Keep it Concise: Use short, preferably single-word tags when possible.
  • Consider Multiple Aspects: Include tags for task type, technique, style, and any special features.
  • Be Consistent: Use a consistent style for multi-word tags (e.g., always use hyphens).
Common Tag Categories:
  • Task Type: AI-translated, AI-generated, etc.
  • Technique: chain-of-thought, few-shot, zero-shot, etc.
  • Style: formal, casual, academic, etc.
  • Special Features: multilingual, code-generation, error-handling, etc.
