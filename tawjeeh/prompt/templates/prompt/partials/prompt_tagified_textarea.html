Creating Effective LLM Prompts with Jinja Syntax
Introduction to LLM Prompt Engineering

Prompt engineering is crucial for effectively instructing Language Models (LLMs) in Natural Language Processing (NLP) tasks. Well-crafted prompts can significantly improve the model's performance and output quality.

Example usage in a prompt:

{% verbatim %}Classify the sentiment of the following text as {% for choice in answer_choices %}{{ choice }}{% if not loop.last %} or {% endif %}{% endfor %}.

Text: {{ input_text }}

Sentiment:
|||
{{ target_column }}{% endverbatim %}

This will render as "Classify the sentiment of the following text as negative or positive." if your answer choices are set to "0:negative,1:positive".

Quick Tip: Type '\\' in the prompt template to see a list of all available dataset columns, i.e., the ones enclosed with {% verbatim %} {{}} {% endverbatim %}.
Using Answer Choices

Answer choices are particularly useful for transforming numeric or coded classes into descriptive labels, making prompts more interpretable for LLMs. Here's how to use them:

  1. Define your answer choices in the designated field (e.g., "0:negative,1:positive" for binary sentiment)
  2. Use the answer_choices variable in your prompt template
  3. Access specific choices using index (e.g., answer_choices[0] for the first choice)
Best Practices for LLM Prompt Creation:
  1. Be Clear and Specific: Clearly state the task and desired output format.
  2. Provide Context: Include relevant background information when necessary.
  3. Use Examples: Incorporate few-shot learning by providing examples when possible.
  4. Control Output Format: Specify the desired structure of the output.
  5. Iterate and Refine: Test your prompts and refine them based on the results.
  6. Leverage Answer Choices: Use descriptive labels to make tasks more intuitive for the model.
Key Elements of Jinja Syntax in Prompts:
  • Variables: {% verbatim %}{{ column_name }}{% endverbatim %} - Insert values from your dataset
  • Control Structures:
    • {% verbatim %}{% if condition %}{% endif %}{% endverbatim %} - Conditional rendering
    • {% verbatim %}{% for item in items %}{% endfor %}{% endverbatim %} - Iterate over lists
  • Comments: {# This won't be rendered #} - Add notes to your prompts
  • Filters: {% verbatim %}{{ text|lower }}{% endverbatim %} - Modify variables (e.g., lowercase)
